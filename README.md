# 📝 Task Management App (Flutter + Provider)

A lightweight and modular task management app built with Flutter. It uses `Provider` for state management and `SharedPreferences` for persistent local storage.

---

## 🚀 Features

- Add, update, and delete tasks
- Persist data locally using SharedPreferences
- MVC  architecture 
- Simple and scalable UI using Flutter widgets
- Provider-based reactive state updates
